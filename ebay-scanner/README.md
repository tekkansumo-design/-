# eBay利益スキャナ（Android）

カメラで商品や値札を写すだけで、eBay で売ったときの見込み利益を自動で計算し、
**設定した金額（初期値 3,000 円）以上の利益が見込めると振動・音・通知で知らせる**アプリです。

## しくみ

1. **端末内で映像を解析**（約 0.7 秒ごと、通信なし・無料）
   - バーコード（JAN / EAN / UPC / ISBN）を読む
   - 日本語 + 英数字の文字を読む（Google ML Kit）
2. **値札の値段**を推定する
   - 一番大きく書かれた金額を優先、「税込」「売価」は加点、「定価」「税抜」は減点
   - 2 回同じ金額が読めたら確定。値札を読んだあと商品に向けても 30 秒間は覚えています
   - 読めないときは「手入力」で入れられます
3. **商品を特定**して eBay（アメリカ）の出品を検索する。確実な順に:
   1. バーコード → eBay の GTIN 検索（信頼度: 高）
   2. 型番・ブランド名（例: `SONY WH-1000XM4`）→ キーワード検索。型番がタイトルに含まれる出品だけで相場を出す（信頼度: 中）
   3. どちらも無い → 写真そのもので eBay の画像検索（信頼度: 低・要確認）
4. **利益を計算**する
   ```
   相場     = 出品価格+送料（USD）の上下20%を除いた中央値
   見込み利益 = (相場 × (1 − 手数料率) − $0.40) × ドル円 − 送料 − 仕入れ値
   ```
   - ジャンク品（部品取り）とオークション形式は除外
   - 「日本から発送している出品」を優先（ライバルと同じ条件の相場）。3 件未満なら全世界で探し直し
   - ドル円は自動取得（6 時間ごと）。手動指定も可
5. 見込み利益がしきい値以上で、出品が 3 件以上あれば**アラート**。
   アラートや「eBayで売れた実績を見る」をタップすると、eBay の**落札済み（Sold）一覧**が開くので、
   実際に売れている値段をその場で確認できます。

値札が読めていないときも、「仕入れ上限 ¥○○（この値段以下なら利益が出る）」が表示されます。

## はじめに: eBay API の鍵を取る（無料）

1. https://developer.ebay.com/ でアカウントを作成（普段の eBay アカウントで可）
2. 「Application Keys」で **Production** の鍵を作る
3. **App ID (Client ID)** と **Cert ID (Client Secret)** をアプリの「設定」に貼り付ける

ユーザーのログインは不要な「アプリケーショントークン」だけを使うので、eBay アカウントの権限は渡しません。
Browse API の無料枠は 1 日 5,000 回です（同じ商品は端末内でキャッシュするので、通常の使い方なら十分）。

## インストール

GitHub の Releases にある `ebay-scanner-<番号>.apk` をスマホで開いてインストールします。
`ebay-scanner/` 以下を変更して push すると、GitHub Actions が自動でビルドして新しい Release を作ります。

## 設定項目

| 項目 | 初期値 | 説明 |
|---|---|---|
| 通知する利益 | 3,000 円 | これ以上でアラート |
| 手数料の合計 | 17 % | 落札手数料・海外手数料・入金/為替コストなど |
| 送料 + 梱包 | 2,500 円 | 商品の大きさに合わせて変えてください |
| ドル円 | 自動 | 手動 150 円 |
| 写真で検索 | ON | バーコードも型番も無いとき |
| 日本発送を優先 | ON | |
| 音 | ON | |

## 注意

- eBay の API で取れるのは**出品中**の価格です（落札価格の API は一般には公開されていません）。
  アラートが出たら、タップして**売れた実績**を確認してから仕入れてください。
- 写真検索（信頼度: 低）は似た別商品に当たることがあります。
- 送料は一律の見込み額です。大きい・重い商品は設定を上げてください。

## 開発

```
cd ebay-scanner
./gradlew testDebugUnitTest   # 値札の読み取り・型番抽出・利益計算のテスト
./gradlew assembleDebug
```

| ファイル | 役割 |
|---|---|
| `FrameAnalyzer.kt` | カメラ映像からバーコード・文字・縮小画像を取り出す |
| `PriceParser.kt` | 値札の金額を推定・安定化 |
| `KeywordExtractor.kt` | 型番・ブランド名の抽出 |
| `ScanEngine.kt` | 商品の特定、eBay 検索、利益判定 |
| `EbayClient.kt` | eBay Browse API と為替 API |
| `Profit.kt` | 相場と利益の計算 |
| `Alerter.kt` | 振動・音・通知 |
