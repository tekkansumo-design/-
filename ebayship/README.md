# eBay 発送管理（Android）

eBay の **Awaiting shipment** を一覧で受け取り、国際郵便マイページで送り状を作り、
二次元コードのメールを拾って、発送後は eBay に追跡番号を戻すまでを1本にしたアプリ。

APK は GitHub Actions が自動で作る。`ebayship/` を変更して push すると
Releases に `ebayship-<番号>` が出るので、スマホのブラウザから .apk を入れる。

## 流れ

1. アプリを開くと自動で eBay から発送待ちを取ってきて、**注文日と商品タイトル**で並べる。
2. 行をタップすると明細。商品タイトル・お届け先住所が出て、
   **商品内容 / 重量 / 個数 / HS コード / 原産国 / 商品金額** を入力する。
3. **決定** で国際郵便マイページが開き、入力済みの内容が自動で流し込まれる。
   画面はそのまま見えているので、確認しながら次へ進み、登録とメール送信まで済ませる。
   終わったら下の **登録できた** を押す。
4. 一覧に戻って **メールを確認** を押すと、
   「国際郵便マイページサービス 二次元コードの送信・印刷用番号の通知」メールを IMAP で読み、
   *▼二次元コード表示* のリンクを注文に結び付ける。
5. 一覧に **二次元コードを表示** ボタンが出る。ラベルを印刷して発送する。
6. 発送したら追跡番号（お問い合わせ番号）を入れて **発送済み** を押すと、
   eBay に追跡番号が登録され、Awaiting shipment から外れる。

## 最初の設定

アプリ右上の「設定」から。

スマホで App ID のような長い文字列を打つのは骨が折れるので、
設定のいちばん上に **まとめて貼り付け** の欄がある。
次のような行を並べて貼り、「取り込む」を押せば一度に入る（JSON でも読む）。

```
環境 = サンドボックス
App ID = xxxxxxxx-xxxxxx-SBX-xxxxxxxxx-xxxxxxxx
Cert ID = SBX-xxxxxxxxxxxx-xxxx-xxxx-xxxx-xxxx
RuName = Xxxx_Yyyy-xxxxxxxx-xxxxxx-xxxxxxxx
```

`App ID` `Client ID` `certid` `RuName` `redirect_uri` などの書き方は読み替える。
Dev ID はこのアプリでは使わないので、混ざっていても捨てる。

### eBay

[developer.ebay.com](https://developer.ebay.com/) でアプリを1つ作り、次の3つを入れる。

| 項目 | どこの値か |
| --- | --- |
| App ID (Client ID) | Application Keys の App ID |
| Cert ID (Client Secret) | Application Keys の Cert ID |
| RuName (redirect_uri) | User Tokens の RuName |

入れたら **eBay と連携する** を押して、eBay にログインして許可する。
飛び先のページが表示できなくてもかまわない。URL に付いてくる認可コードだけ使う。
使う権限は `sell.fulfillment` だけ。

`配送業者コード` は eBay 側の業者名。日本郵便は既定の `JapanPost` のままでよい。

### 国際郵便マイページ

ログイン ID とパスワードを入れておくと、マイページを開いたときに自動で入る
（ログインボタンだけ自分で押す）。

`入力のあと自動で「次へ」を押す` を **押す** にすると、
その画面の欄が全部埋まったときにかぎり自分で次の画面へ進む。
ただし取り消せない **登録・送信は自動では押さない**。
番号が発行されて買い手にも影響する操作なので、最後の一押しは手元に残してある
（画面下の「次へ」ボタンを押せば登録ボタンも文言で探して押せる）。

### 二次元コードのメール（IMAP）

通知メールを受け取っているメールボックスを指定する。
Gmail なら サーバ `imap.gmail.com` / ポート `993` / パスワードは
**アプリパスワード**（2段階認証を有効にしてから発行するもの。通常のパスワードでは入れない）。

### ご依頼主

送り状の差出人。毎回同じなのでここに入れておく。

## 入力欄が自動で入らないとき

国際郵便マイページには公開 API が無く、ページの中身はログインの内側にあるので、
このアプリは **入力欄に付いているラベルの文言から項目を推測して**入れている。
おおよそは当たるが、画面の作りが変わると外れることがある。

外れたときは、その画面で

- **次へ** … その画面の「次へ」「確認」、無ければ「登録」「送信」を文言で探して押す。
- **項目一覧** … その画面にある入力欄をすべて出す。何が居るのか確かめる用。
- **欄を記録** … 押してから入力欄をタップし、どの項目かを選ぶと場所を覚える。
  次からはその画面では推測より記録が優先される。
- 設定の **覚えた入力欄を消す** で全部忘れさせられる。

推測で当たった欄も自動で覚えるので、一度通した画面は次から速い。

## 作りの中身

| ファイル | 役目 |
| --- | --- |
| `MainActivity.kt` | 一覧・明細の画面（中身は `assets/index.html`）と JS からの窓口 |
| `EbayApi.kt` | OAuth、発送待ちの取得、追跡番号の登録 |
| `EbayAuthActivity.kt` | eBay の同意画面から認可コードを受け取る |
| `JpPostActivity.kt` | 国際郵便マイページを開いて流し込む画面 |
| `JpPostScript.kt` | ページに注ぎ込む JavaScript（項目の推測・記録・入力） |
| `MailFetcher.kt` | 通知メールを IMAP で読んでリンクと番号を取り出す |
| `Db.kt` | 設定と注文の保存。秘密は EncryptedSharedPreferences |

## 手元での確認

Android SDK が無くても、構文だけなら kotlinc で見られる。

```
./tools/syntax-check.sh
```

型が合っているかは android.jar が要るので、そこは GitHub Actions のビルドに任せる。

## 気をつけること

- eBay のトークンやパスワードは端末の中だけに置く。どこにも送らない。
- 追跡番号を登録すると買い手に発送通知が飛ぶ。番号を間違えたまま押さないこと。
- 発送済みは一覧に残る。まとめて消したいときは下の「発送済みを一覧から消す」。
