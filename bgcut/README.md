# 背景カット

写真の背景を自動で消して、別の背景に差し替えるアプリです（Photoroom のようなもの）。
ブラウザだけで動き、写真は端末の外に送信されません。スマホではホーム画面に追加するとアプリとして使えます。

## できること

**全自動**
- 写真を複数まとめて選ぶ（ドロップ・貼り付けも可）と、順番に背景削除 → 背景差し替え → 配置まで自動で行う
- 「自動で仕上げる設定」で、取り込み時に使う背景・形（元のまま / 1:1 / 4:5 など）・影を決めておける
- 「すべて保存 (ZIP)」でまとめて書き出し

**あとから修整**（一覧の写真をタップ）
- 切り抜き修整: ブラシで「消す」「戻す」。消えた部分を薄く表示しながら塗れる。硬さ・大きさを調整可。元に戻す / やり直す、自動の結果に戻す
- 境界: 境界を広げる / 狭める、境界のぼかし（縁に背景色が残るときに）
- 背景: 透明・単色・好きな色・グラデーション・元写真のぼかし（被写体を除いた背景だけをぼかす）・好きな画像
- 配置: 縦横比の変更、余白、ドラッグで移動、ピンチで拡大縮小
- 比較ボタンを押している間は元の写真を表示
- 編集内容は端末内（IndexedDB）に自動保存され、閉じて開き直しても続きから修整できる

操作: 2本指で拡大・移動（PC はホイール、スペース＋ドラッグ）、`Ctrl+Z` / `Ctrl+Shift+Z`、`[` `]` でブラシの大きさ、`E` / `R` で消す / 戻す。

## 仕組み

| ファイル | 役割 |
| --- | --- |
| `segment-worker.js` | onnxruntime-web で背景削除モデルを実行（WebGPU があれば使い、なければ WebAssembly） |
| `mask.js` | マスク処理。ガイデッドフィルタで髪の毛などの境界を元画像の輪郭に合わせる、境界の拡張・縮小・ぼかし |
| `app.js` | 一覧・全自動処理のキュー・編集画面・合成と書き出し |
| `store.js` | IndexedDB への保存（元画像、自動結果のマスク、修整後のマスク、設定） |
| `zip.js` | まとめて保存用の ZIP 作成 |
| `sw.js` | オフライン用のサービスワーカー |

マスクは「自動の結果」と「修整後」を別々に持っているので、いつでも自動の結果に戻せます。
境界の調整は修整後のマスクに後からかける方式なので、ブラシで塗った内容を消さずに何度でも調整し直せます。

### モデル

既定は [BRIA RMBG-1.4](https://huggingface.co/briaai/RMBG-1.4)（Hugging Face から初回だけダウンロードし、以後は端末に保存）。
設定から「高画質（約176MB）」に切り替えたり、URL や端末の `.onnx` ファイルを指定して別のモデル（ISNet、U²-Net など）を使ったりできます。

> RMBG-1.4 は **非商用ライセンス** です。商用で使う場合は BRIA と契約するか、
> ISNet（`isnet-general-use.onnx`、Apache-2.0）などのモデルを設定から指定してください。

## 動かし方

ローカルで試す:

```sh
cd bgcut
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages で公開する（スマホから使う場合）:

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `bgcut/` を変更して push すると、`.github/workflows/bgcut-pages.yml` が自動で公開する
   （Actions タブから手動実行も可）
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開き、「ホーム画面に追加」
