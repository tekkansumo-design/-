    商品特定の方法
    
    
    
    無料モードは eBay のキーだけで動きます。似た出品を手本にするので、珍しい商品や
      写真だけでは別の商品になることがあります。バーコードが写っていると確実です。状態は自分で選び、説明文はひな形になります。
    
    
    
    
    Yahoo! デベロッパーネットワークで
      アプリケーションを登録すると無料でもらえます（なくても動きます）。
    
    
     
    
  
    
  
    
    
    Anthropic API かんたん登録（AI を使う場合だけ） 
    
    
    写真から商品を調べて出品文を作る AI（Claude）の鍵です。Claude.ai の有料プランとは別の契約で、使った分だけ料金がかかります。
    
    
      
      
    1. Anthropic のアカウントを作る
        
      メールアドレスか Google アカウントで登録します。
      
        登録ページを開く
      2. 
      
    2. クレジットを買う
        
      前払いです。まずは少額で十分です。自動チャージはオフのままにしておくと使いすぎを防げます。
      
        支払いページを開く
      3. 
      
    3. API キーを作る
        
      「Create Key」を押し、名前（例: ebay）を付けて作ります。表示されたキーは一度しか見られないので、すぐコピーしてください。
      
        キーのページを開く
      4. 
      
    4. キーを貼って確認する
        
      貼ったキーが使えるかを Anthropic に問い合わせてから保存します（確認に料金はかかりません）。
      
        
      
          
      
        
      5. 
    
    
    
    料金の目安: 1 商品の調査で数十円程度（写真の枚数と Web 検索の回数で変わります）。使った額は
      利用状況のページで確認できます。
    
  
    
  
    
    
    eBay API かんたん登録
    
    
    上から順に進めてください。終わった手順には ✅ が付きます。英語のページは ブラウザの翻訳を使うと楽です。
    
    
      
      
    1. eBay 開発者アカウントを作る
        
      いつもの eBay アカウントとは別の登録です（同じメールアドレスで可）。承認まで最大 1 営業日かかることがあります。
      
        登録ページを開く
      2. 
      
    2. 「アカウント削除通知」を免除にする
        
      これをしないと本番のキーが使えません。開いたページの Marketplace Account Deletion で
          「Exempted from Marketplace Account Deletion」をオンにし、理由に「I do not persist eBay data」を選んで保存します。
      
        通知設定を開く
      3. 
      
    3. キーを作って貼り付ける
        
      開いたページの Production で「Create a keyset」を押し、表示されたキーの欄をまとめてコピーして下に貼ります。App ID と Cert ID を自動で見つけます。
      
        キーのページを開く
        
         
      4. 
      
    4. RuName（戻り先の名前）を作る
        
      開いたページで「Get a Token from eBay via Your Application」→「Add eBay Redirect URL」を押し、次の 3 か所に同じ URL を入れて保存します。
      
        
      https://example.com/
      
        
      （Your privacy policy URL / Your auth accepted URL / Your auth declined URL）
      
          保存後に表示される RuName (eBay Redirect URL name) の値をコピーして貼ります。
      
        
      いまの設定は 本番 です。RuName はキーと同じ環境（本番 / Sandbox）のタブで作ってください。
          違う環境の RuName だと、eBay の画面で invalid_request になります。
      
        User Tokens ページを開く
        
      
          
       
      5. 
      
    5. eBay アカウントと連携する
        
      下の「eBay アカウント連携」で「eBay と連携」を押し、同意後に移動した example.com のページの URL を丸ごと貼ります。
          Sandbox（テスト）の場合は、普段の eBay アカウントではなく、開発者サイトの「Sandbox users」で作ったテスト用ユーザーでログインします。
      6. 
      
    6. 出品の準備を自動で行う
        
      ビジネスポリシーの有効化、支払・返品ポリシーの作成、発送元の登録、選択までまとめて行います。
          発送元の郵便番号だけ入れてください。送料ポリシーは送料を決める必要があるので、eBay で 1 つ作ってください（あれば自動で選びます）。
