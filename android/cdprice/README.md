# 中古CD最安値サーチ

アーティスト名を入れると、**ブックオフ・ネットオフ・駿河屋・メルカリ・HMV** の
中古在庫を横断で探して、アルバムごとにいちばん安い店を出す Android アプリ。

同時に **MusicBrainz** からそのアーティストの発売作一覧を引いてくるので、
「何枚出ているうちの何枚が見つかったか」が分かり、抜けている盤は名指しで探し直せる。

## APK の入手

`android/**` を push すると GitHub Actions が両方のアプリをビルドし、
Releases に APK を上げる。スマホのブラウザで Releases を開き、
`cd-price-<番号>.apk` をタップするとインストールできる
（「提供元不明のアプリ」の許可を求められたら許可する）。

## 画面

- 上のチップで検索先のサイトを選ぶ。点の色が進行状況（黄＝取得中、緑＝件数、赤＝失敗）。
- **見つかった順**：見つかった商品を同じ盤どうしまとめ、安い順に並べる。行をタップで商品ページへ。
- **ディスコグラフィ**：MusicBrainz から取った発売作の一覧を発売順に並べ、
  各盤の最安値を横に出す。値段が付いていない盤は「探す」で
  「アーティスト名＋アルバム名」を名指しで検索し直せる。
  まとめて探すボタンもある。同名アーティストが複数いるときは上の選択欄で選び直す。
- **安い順**：まとめずに 1 件ずつ安い順。
- 「中古のみ」「キーワード一致」「上限円」でしぼり込み。
- CSV で結果を共有できる。

価格は検索結果に出ている金額で、**送料・手数料は含まない**。

「中古」かどうかは、ネットオフとメルカリのように中古しか扱わないサイトはそのまま中古、
駿河屋・HMV・ブックオフのように新品と中古が混ざるサイトは商品欄の表記（「中古」「USED」）と
URL で見分けている。表記が変わると新品として扱われてしまうので、
件数はあるのに何も出ないときは「中古のみ」を外して確かめる。
上の状態表示に「商品 N 件（表示 M 件）」と両方出るので、しぼり込みで消えたのか分かる。

## 仕組み

サイトの HTML は予告なく変わるので、「この CSS クラスを読む」という書き方をしていない。
代わりに、どの通販サイトにも共通する形だけに頼る（`Extract.kt`）。

1. 価格らしき文字列を持つ **いちばん内側の要素** を全部拾う
2. そこから親を辿り、同じホストの商品リンクを含む最初の箱を **商品カード** とみなす
3. カードから題名・画像・金額を取る（ポイントや送料の数字は除く。定価と併記なら安いほう）

価格と商品リンクが対になっていない箇所（ヘッダの「送料無料」やおすすめ枠）は自然に落ちる。
`¥` と数字が別の `<span>` に割れている今どきの作りにも当たる。

検索 URL も決め打ちにせず、三段構えで探す（`Finder.kt`）。

1. 候補をいくつか順に試し、商品が取れた形を覚える（次回はそれを最初に使う）
2. 全滅したらトップページの検索フォームから URL を組み立てて試す
3. それでも 0 件なら、描画待ちが要るページとみて WebView で取り直す

メルカリは最初から JavaScript 描画とわかっているので、はじめから WebView で取る。

### アルバム一覧

一覧は MusicBrainz の Web Service v2 から取る（`MusicBrainz.kt`）。
鍵は要らないが、素性の分かる User-Agent と 1 秒に 1 回までという約束があるので守っている。

- アーティスト検索 → 候補を出し、いちばん確からしいものを既定にする
- その MBID で release-group（アルバム・EP・ベスト）を引き、発売の古い順に並べる
- 同じ題名の重複は古いほうを残す

一覧の題名と店の商品名は、飾りを落として突き合わせる（「【中古】First Love / 宇多田ヒカル」
＝「First Love」）。日本のアーティストは英語表記で登録されていることがあるので、
店の検索には利用者が入力した語をそのまま使い、MusicBrainz は一覧を得るためだけに使う。

## 取れなくなったときの直し方

サイトのリニューアルで 0 件になったら、**診断** 画面を開く。

- サイトごとに検索 URL の形（`{q}` がキーワードの位置）を書き換えて「試す」
- 状態・HTML の長さ・金額表記の有無・取れた件数が出るので、どこで失敗しているか分かる
- 取れたら「保存」。以後その形を使う（アプリを作り直さなくてよい）
- 「HTMLを共有」で実際に返ってきた HTML を送り出せる
- アルバム一覧が出ないときは、いちばん上の「アルバム一覧（MusicBrainz）」の「試す」で
  候補と取れた枚数を確かめる

## 開発

```
cd android
./gradlew :cdprice:testDebugUnitTest   # 抽出の試験
./gradlew :cdprice:assembleDebug       # APK
```

`src/test/.../ExtractTest.kt` は、通販サイトでよくある並び方を再現した疑似 HTML で
抽出を確かめている。実サイトには当てられないので、構造の型で押さえる形にしてある。
